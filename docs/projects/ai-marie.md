# AI-MARiE

AI-Based Machine Activity Recognition on the Edge

## Project overview

AI-MARiE aims to develop machine learning methods for automatically recognizing industrial machine activities using
signals from internal Controller Area Network (CAN) buses. The project focuses on forklift trucks and explores
self-supervised learning to exploit large amounts of unlabeled data, reducing the need for costly manual labeling.

## Research objectives

A key challenge is developing models that generalize across different machines, operators, and working environments. The
project aims to achieve human-level activity recognition performance and demonstrate real-time operation using onboard
edge computing on forklift trucks.
