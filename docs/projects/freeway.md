# FREEWAY

Automating asynchronous federated learning and edge computing for efficient vehicle operation analytics

## Project overview

FREEWAY develops digital services for electromobility using asynchronous federated learning, edge computing, and machine
learning operations (MLOps). The project addresses the challenges of scaling machine learning across large,
heterogeneous vehicle fleets, aiming to improve operational efficiency, safety, and uptime.

## Research focus

The project advances software capabilities on vehicle edge devices and back-end systems. It develops MLOps workflows
tailored to asynchronous federated learning, including data retrieval, model versioning, automated testing, validation,
and deployment.

Key applications include:

- Energy consumption forecasting
- Vehicle operation profiling and activity recognition
- Anomaly detection

Through demonstrations in real-world use cases, FREEWAY investigates how federated edge intelligence can support
practical digital services for electromobility.
